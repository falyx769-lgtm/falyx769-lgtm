# Портфолио QA Engineer

За спиной — десятилетия опыта в управлении качеством сложных технических процессов. Это научило меня:
- Выявлять корень любой проблемы;
- Объяснять сложные вещи простым языком;
- Реализовывать каждую задачу до конца.

## 📱 Пример кейса: складной смартфон (Samsung Galaxy Z Flip7)

**Дефект в VK Клипов:** при сгибе экрана (~90°) пропадает панель действий (лайк, комментарии, репост) — видео воспроизводится без элементов управления. При этом ОС корректно распознаёт Flex-режим (активируется системная сенсорная панель в нижней половине экрана), но приложение игнорирует согнутое состояние.

Дополнительно: при сгибе пропадает и блок автора с рекламным боксом — монетизируемый элемент недоступен в Flex-режиме

**Ожидаемое поведение:** панель действий сохраняется и адаптируется под Flex-раскладку (видео в верхней половине, элементы управления в нижней).

## 📺 Пример кейса 2: обрезание контента в Flex-режиме (Samsung Galaxy Z Flip7)

**Дефект в разделе «Фильмы и сериалы» → «Вы смотрели»:** при сгибе экрана (~90°) карточка просмотренного контента обрезается по границе Flex-раскладки: название («Тихий Дон. Серия 1»), метка студии и позиция воспроизведения (пауза на 1:41:29) становятся недоступны, полоса прогресса не отображается. Дополнительно: превью-кадр после сгиба не соответствует сохранённой позиции воспроизведения.

**Ожидаемое поведение:** карточка масштабируется или переносится в видимую область верхней половины экрана; превью соответствует позиции паузы.
